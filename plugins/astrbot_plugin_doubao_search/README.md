# astrbot_plugin_doubao_search（豆包搜索 · 联网搜索）

> 基于 Agent Plan 豆包搜索 API 的联网搜索。按会话开启后，模型可自动检索实时信息；未开启时遇到难解问题会主动询问是否联网搜索。

## 功能特性

- **按会话开关**：每个群聊 / 私聊会话独立记忆开关状态，互不影响
- 开启后，LLM 在需要时**自动调用搜索**获取实时信息（新闻、行情、新版本等）
- 未开启时，遇到明显需要联网的问题会**主动询问**是否临时联网
- 搜索结果条数与正文长度可配置

## 命令

| 命令 | 说明 |
| --- | --- |
| `/联网搜索 开` | 在当前会话开启联网搜索 |
| `/联网搜索 关` | 在当前会话关闭联网搜索 |
| `/联网搜索 状态` | 查看当前会话的开关状态 |

## 配置

| 配置项 | 说明 |
| --- | --- |
| `api_key` | 豆包搜索 API Key；**留空则自动读取主配置中 Ark provider 的 key** |
| `count` | 搜索返回条数（1-10） |
| `content_len` | 单条结果正文截断长度（字符） |

## 注意事项

- 联网搜索会产生额外的 API 调用与 token 消耗，群内长期开启请注意用量
- 开关按会话（群/私聊维度）生效，换群需重新开启

## 安装

放入 AstrBot 的 `data/plugins/` 目录后重载插件，在 WebUI 插件配置中填写 API Key（或留空复用 Ark 配置）。
