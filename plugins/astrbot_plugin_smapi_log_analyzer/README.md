# astrbot_plugin_smapi_log_analyzer（SMAPI 日志分析）

> 自动识别群里的 smapi.io/log 日志链接，本地解析提取错误与问题模组，再由大模型综合成自然语言诊断和修复建议（LLM 失败时回退规则分析）。

## 功能特性

- **自动识别**：群里直接发 `smapi.io/log/…` 链接即可触发分析，无需命令
- **本地解析**：抓取日志后先在本地提取错误等级、异常信息与问题模组，作为事实底座
- **AI 诊断**：由大模型把解析结果综合成自然语言诊断结论与修复建议
- **规则兜底**：LLM 调用失败时自动回退到规则分析，保证一定有输出
- **LLM 工具**：注册 `smapi_log_analysis` 工具，可在对话中被智能调用

## 命令

| 命令 | 别名 | 说明 |
| --- | --- | --- |
| `/smapi <链接>` | `日志分析`、`log分析` | 分析指定的 smapi.io 日志链接 |

## 使用示例

```
/smapi https://smapi.io/log/xxxxxxxx
```

或者直接把 `https://smapi.io/log/…` 链接发到群里，机器人会自动分析。

## 配置

支持 AstrBotConfig 标准配置（WebUI 插件配置页），无需手动编辑文件。

## 注意事项

- smapi.io 上的日志**保存 30 天**，过期链接无法分析
- 仅支持 SMAPI（星露谷物语模组加载器）日志格式

## 安装

放入 AstrBot 的 `data/plugins/` 目录后重载插件即可。
