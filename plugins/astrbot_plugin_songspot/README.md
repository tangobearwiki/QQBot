# astrbot_plugin_songspot（点播）

> 点播服务器本地歌曲（RVC 翻唱发布渠道），命中歌曲以语音发送。

## 功能特性

- 从服务器本地曲库（`data/songs/` 目录）模糊搜索歌曲
- 关键词命中**唯一**歌曲时直接以语音发送，可配合 RVC 翻唱流程发布成品
- 曲库列表一键查看

## 命令

| 命令 | 说明 |
| --- | --- |
| `/点播 <关键词>` | 按关键词点播歌曲，命中唯一即以语音发送 |
| `/点播列表` | 列出曲库里全部歌曲 |

## 使用示例

```
/点播 星露谷
/点播列表
```

## 添加歌曲

把 mp3 文件放入服务器目录：

```
/opt/astrbot/data/songs/
```

之后即可被点播命中；目录为空时 `/点播列表` 会提示曲库为空。

## 注意事项

- 仅支持本地曲库点播，不支持在线搜索
- 曲库空时会提示先把 mp3 放入 `data/songs/`

## 安装

放入 AstrBot 的 `data/plugins/` 目录后重载插件即可。
