# astrbot_plugin_wake_ban

> 对话唤醒权限管理插件：`/ban` 禁用某人的对话唤醒权限，`/unban` 解除，`/banlist` 查看名单。被禁用户 @ 机器人不再触发对话，斜杠命令与工具查询（ss 查询、smapi 日志分析等）不受影响。

## 功能特性

- **用户级 / 群级** 两种封禁粒度，互不影响
- 支持临时封禁（到时自动解封）与永久封禁
- **只封对话，不封工具**：被禁用户仍可使用 `/` 开头的命令与工具类查询
- 名单持久化存储，机器人重启不丢失
- 无需任何配置，装上即用

## 命令一览

| 命令 | 权限 | 说明 |
| --- | --- | --- |
| `/ban @某人 [时长] [理由]` | 管理员 | 禁用指定用户的对话唤醒 |
| `/ban QQ号 [时长] [理由]` | 管理员 | 同上，支持直接写 QQ 号 |
| `/ban group [时长] [理由]` | 管理员 | 在群聊中禁用**本群**的对话唤醒（`/ban 群` 等效） |
| `/unban @某人` 或 `/unban QQ号` | 管理员 | 提前解除指定用户 |
| `/unban group`（`/unban 群`） | 管理员 | 恢复本群的对话唤醒 |
| `/banlist` | 所有人 | 查看名单：被禁用户/群、理由、生效时间、到期时间与剩余时长 |

## 时长格式

| 写法 | 含义 |
| --- | --- |
| `30s` | 30 秒 |
| `10m` | 10 分钟 |
| `2h` | 2 小时 |
| `7d` | 7 天 |
| 不填 / `永久` / `perm` / `permanent` | 永久封禁 |

> 注意：数字必须带单位，`/ban @某人 30` 会被拒绝并提示正确格式；数值必须为正整数。

## 生效范围

**会被拦截：**

- 被禁用户 @ 机器人发起的闲聊对话
- 群级禁用后，全群成员的闲聊对话（私聊不受影响）

**不受影响：**

- 所有 `/` 开头的斜杠命令
- 工具类查询（音乐、天气、wiki、ss 查询、smapi 日志分析等）
- 用户级与群级相互独立：只 ban 群不 ban 人时，该用户私聊机器人仍正常

## 自动解封

每条消息都会触发到期检查，临时封禁到期后自动解除，无需手动操作，也不会出现在名单里。

## 数据存储

封禁名单保存于：

```
data/plugin_data/astrbot_plugin_wake_ban/banned.json
```

包含被封对象、理由、操作人、时间与到期时间戳。删除该文件即可清空全部封禁记录。

## 安装

将本插件放入 AstrBot 的 `data/plugins/` 目录（或通过 AstrBot 插件市场安装），重载插件后即可使用。

## 版本

当前版本：**v1.2.0**（AstrBot 插件标准结构，`metadata.yaml` 描述见仓库）
