# astrbot_plugin_sensenova_t2i（商汤日日新生图）

> 基于商汤日日新 SenseNova U1.5 的 AI 生图与改图插件，提供 `/画图`、`/改图` 命令，并注册 LLM 工具供自然语言直接调用。

## 功能特性

- **文生图**：`/画图 描述` 一句话生成图片，支持比例参数
- **图生图改图**：回复一张图片发 `/改图 修改要求`，即可修改图片内容
- **LLM 工具集成**：注册 `sensenova_text_to_image` 与 `sensenova_image_edit` 工具，配合意图引导，群友用自然语言（如"帮我画一只猫"）即可触发生图 / 改图
- 请求超时时间、生图模型可配置

## 命令

| 命令 | 别名 | 说明 |
| --- | --- | --- |
| `/画图 <描述>` | `生成图片` | AI 生图，可追加比例参数，如 `/画图 赛博朋克城市 --16:9` |
| `/改图 <修改要求>` | `修改图片`、`编辑图片`、`p图`、`P图` | **回复一张图片**并发送命令，按要求修改图片 |

## 配置

| 配置项 | 说明 |
| --- | --- |
| `api_key` | SenseNova API Key（`sk-` 开头），在 [日日新开放平台](https://platform.sensenova.cn/) 申请 |
| `model` | 生图模型 ID |
| `timeout` | 生图请求超时（秒） |

## 使用示例

```
/画图 星空下的鲸鱼水族馆
/画图 像素风小镇 --16:9
（回复一张图片）/改图 把天空换成黄昏
```

## 注意事项

- 改图必须**回复目标图片**后发送命令，否则无法定位图片
- 生图耗时与模型排队情况相关，超时可在配置中调大

## 安装

放入 AstrBot 的 `data/plugins/` 目录后重载插件，在 WebUI 插件配置中填写 API Key。
