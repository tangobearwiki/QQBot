# astrbot_md_cleaner（Markdown 清理器）

> 发送前剥离 LLM 回复中的 Markdown 语法，保证 QQ 端纯文本显示效果。

## 功能特性

- 在消息**发送前**自动拦截并清理文本：剥离加粗、标题、列表符号、代码围栏等 Markdown 语法残留
- 无需任何命令或配置，安装重载后对所有 LLM 回复自动生效
- 只处理文本消息段，图片、语音等组件不受影响

## 适用场景

QQ 客户端不支持 Markdown 渲染时，LLM 输出的 `**加粗**`、`# 标题`、`- 列表` 等符号会原样露出，影响阅读。本插件在框架发送环节统一清洗，输出干净的纯文本。

## 配置

无配置项，即装即用。

## 安装

放入 AstrBot 的 `data/plugins/` 目录后重载插件即可。

## 版本

当前版本：**v1.0.0**
