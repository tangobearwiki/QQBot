# sdv_wiki_query（星露谷 Wiki 查询）

> 发送 `ss 关键词` 同时检索星露谷物语**原版 / SVE / RSV** 三个维基，本地词条模糊匹配（错别字、拼音容错），原版链接自动转 b23 短链。

## 功能特性

- **三库并发检索**：原版维基（biligame）、SVE 维基、RSV 维基一次查询全部覆盖
- **本地词条模糊匹配**：内置三库词条表，支持错别字、拼音容错，先本地精确匹配再联网搜索
- **短链优化**：原版维基长链接自动转 b23.tv 短链（并发限流），手机端友好
- 无需 @ 机器人，消息以 `ss` 开头即触发

## 用法

```
ss <关键词>
```

- 关键词 1-50 个字符
- 示例：`ss 星之果实`、`ss 上古鱼`、`sve 华丽的戒指`

## 检索逻辑

1. 消息匹配 `ss` 前缀后提取关键词
2. 本地词条表模糊匹配（容错错别字 / 拼音）
3. 并发请求三个维基的搜索 API（原版走 biligame opensearch，SVE/RSV 走 MediaWiki `list=search`）
4. 汇总三库结果回复：精确匹配优先，否则取最相关结果

无配置项，装上即用。
