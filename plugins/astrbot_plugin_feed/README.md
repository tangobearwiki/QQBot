# astrbot_plugin_feed（投喂 · 米饼统计）

> 投喂赞助入口与米饼余量统计：每消耗 1000 万 LLM token 记为消耗一块米饼，管理员可设置、增加、查询和重置。

## 功能特性

- `/投喂` 发送随机求投喂文案（鱼缸 / 米饼人设）与两张本地收款码图片
- **米饼计量**：LLM token 消耗自动折算为米饼（1000 万 token = 1 块米饼）
- 统计数据持久化存储，重启不丢失

## 命令

| 命令 | 权限 | 说明 |
| --- | --- | --- |
| `/投喂` | 所有人 | 发送随机求投喂文案及两张本地收款码 |
| `/米饼 查询` | 管理员 | 查看当前米饼余量与累计消耗 |
| `/米饼 设置 <数量>` | 管理员 | 直接设定米饼余量 |
| `/米饼 增加 <数量>` | 管理员 | 增加米饼（收到赞助后入账） |
| `/米饼 重置` | 管理员 | 清零累计 token 消耗计数 |

## 使用示例

```
/米饼 增加 10      ← 收到 10 块米饼的赞助后入账
/米饼 查询         ← 查看余量与已消耗
```

## 配置

无独立配置项；收款码图片与文案在插件目录内维护。

## 安装

放入 AstrBot 的 `data/plugins/` 目录后重载插件即可。
