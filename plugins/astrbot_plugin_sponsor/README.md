# 赞助共建插件

## WebUI

登录 AstrBot 控制台后，在已安装插件中找到“赞助共建”，进入插件页面；也可访问：

`/#/plugin-view/astrbot_plugin_sponsor/sponsor`

页面提供四个工作区：登记与到账、权益管理、运营台账、功能共创。

- 登记时可选择“已核对实际到账”，立即发放 30 天权益并计入公示。
- 未勾选则保存为待确认，不发放权益、不计入公示；核实后点击“确认到账”。
- 权益可搜索、续期和撤销；续期会新增一笔已确认收入，撤销不删账、不退款。
- 可设置本月运营目标、登记收支、调整功能候选状态。
- 接口继承控制台插件页面鉴权，不开放无鉴权管理端口，不连接支付平台。

## 聊天端

普通用户保留 `/赞助`、`/我的权益`、`/赞助名单`、`/赞助公示`、`/功能投票`；`/投喂` 继续使用原插件收款码。旧 `/赞助管理` 命令仍兼容，其登记默认已确认。

数据：`/opt/astrbot/data/plugin_data/astrbot_plugin_sponsor/sponsor.json`，请纳入受保护备份。公开名单只显示有效、主动公开昵称的记录。
