# 星露谷联机匹配

AstrBot 插件：按平台池（PC / 手机 / Switch / PlayStation / Xbox）做 FIFO 匹配，跨群共享同一个队列；匹配成功后私聊双方交换 QQ / Steam 好友码，群内只发匿名提示。

## 功能

- 报名问卷 8 步：平台、原版/模组、可玩时段、目标人数、自己的性别、希望对方的性别、联系 QQ、Steam 好友码。
- 问卷中随时回复 **“上一步”** 可退回上一题修改。
- 性别偏好是双向硬条件：双方都满足对方的偏好才会匹配；“保密”只匹配“不限”。
- WebUI 插件详情页内置 **统计面板**（今日报名/匹配/成功率/排队/活跃群/举报、各平台池排队、按小时趋势、最近匹配），每 5 秒自动刷新。
- 统计页下方提供 **管理操作**：立即撮合、手动强制配对（**无视平台/模式/人数/时段/性别等所有条件**）、封禁/解封、踢出队列、解散匹配、标记举报已处理。
- 普通匹配会按等待时间自动放宽条件：默认等待 30 分钟放宽人数、60 分钟放宽原版/模组、90 分钟放宽时段；可在插件配置里调整，设为 0 表示不启用。
- `/p` 命令和报名问卷会设置 `event.call_llm = False`，不会触发 AstrBot 的默认 LLM，报名全程零 token。
- 拒绝/取消/完成后队列会正确关闭，不会卡住无法重新报名。

## 命令

| 命令 | 说明 |
|---|---|
| `/p 报名` | 报名（群内触发后走私聊问卷，回复“上一步”可回退） |
| `/p 状态` | 查看排队 / 匹配状态 |
| `/p 取消` | 退出队列或取消匹配 |
| `/p 确认` | 确认匹配 |
| `/p 拒绝` | 拒绝匹配（默认冷却 10 分钟） |
| `/p 完成` | 结束本次联机 |
| `/p 举报 @某人 原因` | 举报 |
| `/p 帮助` | 命令说明 |
| `/p 封禁 @某人 [7d]` | 管理员：封禁 |
| `/p 解封 @某人` | 管理员：解封 |
| `/p 统计` | 管理员：今日统计 |
| `/p 解散 <ID>` | 管理员：强制解散匹配 |
| `/p 队列` | 管理员：查看各池排队人数 |

## 数据

- SQLite：`data/match.db`（WAL 模式）
- 只保存报名必需字段；联系方式仅私聊交换，群内不展示。

## 配置

在 AstrBot 插件配置页修改：

- `admins`：管理员 QQ 列表
- `confirm_timeout_sec`：确认时限（默认 300 秒）
- `cooldown_sec`：拒绝冷却（默认 600 秒）
- `queue_ttl_sec`：排队有效期（默认 7200 秒）
- `match_interval_sec`：扫描间隔（默认 10 秒）
- `anonymous_notice`：群内匿名提示开关

## 说明

- 平台池是硬条件：PC / 手机 / Switch / PlayStation / Xbox 互不匹配。
- 原版与模组不混排；目标人数需一致；可玩时段至少有一个重叠。
